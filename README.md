# Revisio downloads

PDF markup and quantity takeoff for construction drawings.

**[Download the latest Windows installer](https://github.com/m3mcginnis/revisio-releases/releases/latest/download/Revisio-Setup.exe)** (always the newest version).

- Installs for your user account and registers Revisio for `.pdf` files ("Open with Revisio").
- Always current: the installer checks for a newer release before installing, and the app updates itself at launch, every two hours, and from **Help → Check for updates**.
- The installer isn't code-signed yet, so Windows SmartScreen asks first: choose **More info → Run anyway**.

Revisio was previously named Plan C, and before that Markitect. Existing installs update to Revisio automatically and keep their settings.

This repository only hosts installers and the update feed; the "Source code" archives GitHub attaches to each release contain just this README.
