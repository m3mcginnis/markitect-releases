# PDF Ruler — downloads

**Measure twice. Markup once.** PDF markup and quantity takeoff for construction drawings.

Download the latest Windows installer from **[Releases](https://github.com/m3mcginnis/pdf-ruler-releases/releases/latest)**: `PDF-Ruler-Setup-<version>.exe`.

- Installs for your user account and registers PDF Ruler for `.pdf` files ("Open with PDF Ruler").
- Updates itself: it checks at launch, every two hours, and from **Help → Check for updates**.
- The installer isn't code-signed yet, so Windows SmartScreen asks first: choose **More info → Run anyway**.

PDF Ruler was previously named Markitect. Existing installs update to PDF Ruler automatically and keep their settings.

This repository only hosts installers and the update feed; the "Source code" archives GitHub attaches to each release contain just this README.
