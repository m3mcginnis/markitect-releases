# Plan C — downloads

**Because B was taken — and this one's better.** PDF markup and quantity takeoff for construction drawings.

**[Download the latest Windows installer](https://github.com/m3mcginnis/plan-c-releases/releases/latest/download/Plan-C-Setup.exe)** (always the newest version).

- Installs for your user account and registers Plan C for `.pdf` files ("Open with Plan C").
- Always current: the installer checks for a newer release before installing, and the app updates itself at launch, every two hours, and from **Help → Check for updates**.
- The installer isn't code-signed yet, so Windows SmartScreen asks first: choose **More info → Run anyway**.

Plan C was previously named Markitect. Existing installs update to Plan C automatically and keep their settings.

This repository only hosts installers and the update feed; the "Source code" archives GitHub attaches to each release contain just this README.
